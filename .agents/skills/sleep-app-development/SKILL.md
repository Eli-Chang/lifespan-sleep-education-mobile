# Sleep App Development

Use this skill for substantial work in this repository. Verify the project root and applicable instructions first. Triage the request, freeze requirements, select the minimum complete agents from `references/agent-routing.md`, investigate read-heavy concerns in parallel, use one primary application-code writer, then run browser, accessibility, privacy, clinical, reliability, and native checks when relevant. Finish with an independent final verification and evidence; browser phone emulation is not native testing.

Never write outside the project root, expose secrets, use real health information, change approved clinical content without authorization, or claim native validation from Expo Web.

## Workflow

1. Inspect boundary, package scripts, routes, content, state, persistence, AI, narration, tests, and environment.
2. For substantial work, run `app_planner` before implementation and freeze the ledger.
3. Route only relevant specialists; do not invoke every agent for every task.
4. Use `app_implementer` as the sole overlapping application writer.
5. Run focused tests, Playwright, visual, accessibility, privacy, clinical, reliability, and native checks as routed.
6. Resolve defects and run `final_verifier` before reporting completion.

See `references/agent-routing.md`, `references/qa-matrix.md`, and `references/app-safety-rules.md`.
